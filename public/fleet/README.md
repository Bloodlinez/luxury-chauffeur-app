# Fleet imagery

Place final luxury vehicle photographs in this folder using these filenames:

- `business-class.jpg` — black BMW 5 Series (visual identity for Business Class; customer label remains Mercedes E-Class or Similar)
- `first-class.jpg` — black Mercedes-Benz S-Class luxury sedan
- `luxury-suv.jpg` — black Cadillac Escalade or Escalade ESV

Until these files are present, the UI shows distinct dark category placeholders with category-specific silhouettes.
Do not use sports cars, Porsche, Camaro, or Infiniti QX80 imagery.
